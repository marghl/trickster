# `underground_01`

This directory defines the first unnamed underground persona. The identifier is deliberately technical and has no in-world meaning. No canonical name is published or stored here.

Current interaction:

- `stray_sound`: a quiet, ordinary Minetest Game sound placed behind or beside a solitary player deep underground.

Activation approaches zero at Y = -500 and reaches its maximum depth factor at Y = -2500. It also depends on time spent underground and strongly prefers the absence of nearby witnesses.
